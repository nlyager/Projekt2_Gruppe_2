## Getting Started

Follow these steps to set up the database and run the application locally.

### 1. Set Up the Database

Execute the following SQL scripts in the specified order:

1. **`src/main/resources/mySQL_Setup.sql`**  
   Creates the database and its tables.

2. **`src/main/resources/mySQL_Data_Setup.sql`**  
   Populates the database with sample data.

### 2. Run the Application

Once the database has been configured, start the application by running:

`Projekt2Gruppe2Application`

The application should now be available locally at:

`http://localhost:8080`
